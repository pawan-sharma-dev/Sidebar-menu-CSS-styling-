# CSS Collapsible Navbar

A simple collapsible navigation bar built using HTML and CSS. The menu expands and collapses when you click the hamburger icon using the checkbox technique, with no JavaScript.

## Features
- Expandable and collapsible navbar
- Pure HTML and CSS
- Checkbox-based toggle functionality
- Interactive hamburger menu
- Simple and clean UI

## Technologies Used
- HTML5
- CSS3
